# Generated automation reports

Each suite runner (`test:cart`, `test:login`, `test:home-shopping`, or `test:shopping`) creates a unique suite-prefixed timestamped subfolder here containing:

- `extent.html`: Spark Extent report generated by the `cucumber-js-extent` adapter.
- `cucumber.html` and `cucumber.json`: Cucumber reports for diagnostics/integration.
- `artifacts/`: per-scenario Playwright traces, plus screenshots embedded in reports on failure.

Generated run folders are gitignored and previous reports are preserved. Spark uses externally hosted styling assets; the standard Cucumber HTML report is also available.
